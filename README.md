# Учебная практика по компьютерному зрению

Каркас проекта для выполнения учебной практики по детекции объектов.

## Что уже есть

- структура проекта под `data/`, `src/`, `configs/`, `results/`;
- CLI на Python;
- заготовки под пайплайн, отчётные таблицы и будущие модели;
- совместимость с `uv`.

## Запуск

```bash
uv run practica --mode summary
uv run practica --mode scaffold
```

## Следующие шаги

1. Скачать датасет и положить его в `data/raw/`.
2. Добавить конвертер разметки в `data/processed/`.
3. Подключить 5 моделей детекции.
4. Запустить обучение и сохранить метрики в `results/`.
