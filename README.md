# Project

This repository contains a computer vision pipeline for object detection experiments.

- загрузка датасета;
- приведение аннотаций к единому формату;
- предобработка изображений;
- обучение нескольких моделей;
- расчет метрик качества;
- сравнительный анализ результатов.

Основные метрики:

- `Precision`
- `Recall`
- `F1`
- `mAP@0.5`

## Выбранный датасет

Базовый вариант для проекта: `KITTI` object detection dataset.

Сейчас в репозитории датасет еще не добавлен, но структура уже подготовлена:

- `data/raw/` для исходных данных;
- `data/processed/` для преобразованных аннотаций и подготовленных выборок.

## Что уже есть

- структура проекта под `data/`, `src/`, `configs/`, `results/`;
- CLI на Python;
- заготовки под пайплайн, отчетные таблицы и будущие модели;
- совместимость с `uv`.
